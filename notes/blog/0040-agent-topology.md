# c0040 agent 拓扑图

- 一句话设计：确定性骨架，LLM 只开一个窄口。六个机制（上下文、工具边界、状态机、验证、失败恢复、评估）都是围着这个窄口长出来的，画成图之后这件事一眼可见。
- 状态机画出来才发现口述漏了一条边：rolled_back 之后同裁决同目标不会再提案（suppressed），目标值移动才重提。
- 失败恢复按「方向」上色比按模块分更好讲：所有失败只流向两种颜色，安全停住或交给人，没有一条流向「继续放行」。
